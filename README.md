# Obsidian Kanban Plugin

**The Kanban plugin is looking for new maintainers.** Interested? [Read more here.](https://github.com/mgmeyers/obsidian-kanban/blob/main/MAINTAINERS.md)

> [!NOTE]
> This is a modified fork of the Obsidian Kanban plugin, so this version will not be available through the Obsidian Community Plugins. However, I do plan to maintain this for my own purposes and anyone else who is looking for specific features. I will not be fixing bugs or adding features based on the original repository unless the original maintainer reaches out, but I am more than happy to add requested features here if I am able. Thank you!
